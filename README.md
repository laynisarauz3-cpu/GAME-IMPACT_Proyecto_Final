# 🎮 GAME IMPACT

## Videojuegos y desarrollo personal

Proyecto web desarrollado como actividad final de HTML5, CSS3 y JavaScript.

La página web presenta información sobre los videojuegos y su posible influencia en el desarrollo de diferentes habilidades, además de explicar sus beneficios, riesgos y la importancia de utilizarlos de manera responsable.

## 🎯 Objetivo del proyecto

El objetivo de GAME IMPACT es presentar de una manera interactiva y visual cómo los videojuegos pueden relacionarse con diferentes habilidades como:

- 🧠 Pensamiento crítico
- 🧩 Resolución de problemas
- 🎯 Atención
- 🤝 Trabajo en equipo
- 🎨 Creatividad
- ⚡ Reacción
- 🗺️ Planificación
- 💬 Comunicación
- 🔄 Adaptación
- 🏆 Perseverancia

También se presentan algunos posibles aspectos negativos relacionados con el uso excesivo de los videojuegos.

---

## 🎮 Videojuegos incluidos

El proyecto contiene información sobre diferentes videojuegos:

- ⛏️ Minecraft
- 🔥 Free Fire
- ⚔️ Mobile Legends
- 🧱 Roblox
- 🚗 Grand Theft Auto
- 👑 Honor of Kings

Cada videojuego cuenta con información específica, incluyendo:

- Descripción
- Aspecto positivo
- Posible aspecto negativo
- Dato curioso

## ⚙️ Funciones del proyecto

La página incluye diferentes elementos interactivos:

- 🎮 Menú de navegación
- 🔎 Información individual de cada videojuego
- 🪟 Ventanas modales
- 🧠 Sección de beneficios
- ⚡ Sección de habilidades
- ⚖️ Comparación entre aspectos positivos y negativos
- 🎮 Recomendaciones para un uso responsable
- 🏆 Cuestionario interactivo
- 📊 Sistema de puntuación
- 🌙 Modo oscuro
- ☀️ Modo claro
- 🎨 Fondo con efecto RGB
- ✨ Bordes con efectos RGB
- 📱 Diseño adaptable para dispositivos móviles
- 📝 Formulario interactivo

---

## 🌈 Diseño

El diseño utiliza una estética inspirada en el mundo gamer, utilizando colores RGB, efectos luminosos, bordes animados, tarjetas, botones y diferentes elementos visuales.

La página también utiliza una estructura responsive para adaptarse a diferentes tamaños de pantalla.
